# SACRED CANOPY v3.1

## Updates in this package
- Live subscription for the public Help page announcement (`siteSettings/maintenanceNotice`).
- Admin console tab for managing activities and announcements (`siteActivities`): create, edit, enable/disable, and delete.
- Home page activity banner with a botanical fallback banner when no active activity exists.
- Header notification bell showing active maintenance notices and site activities.
- Responsive header navigation with History moved into the signed-in profile dropdown.
- Mascot is larger and mirrored to face left; chatbot panel has a resizable/scrollable frame.
- Google sign-in button prevents duplicate popup requests and explains `auth/cancelled-popup-request`.
- Contact page includes QR/link sharing controls and an existing mascot asset.

## Run locally
```powershell
npm install
npm run dev
```

## Verify before deployment
```powershell
npm run build
```

## Deploy
Deploy the Firestore rules first (needed for `siteActivities`):
```powershell
firebase use sacred-canopy-168ef
firebase deploy --only firestore:rules
firebase deploy --only hosting
```

## Important
- Do not deploy service-account private keys to the web project.
- Admin-only writes rely on Firebase Auth Custom Claims (`admin: true`); a profile's `role` field alone is not sufficient.
- `siteActivities` is publicly readable and can only be changed by users with the trusted Admin custom claim.
- The QR image is generated by an external QR service at runtime. If you prefer a fully offline QR asset, replace it with a locally generated QR code.
- This environment could not complete a build because the ZIP's `node_modules` did not contain platform-specific optional packages. Run `npm install` on your Windows computer, then `npm run build` before deploying.
