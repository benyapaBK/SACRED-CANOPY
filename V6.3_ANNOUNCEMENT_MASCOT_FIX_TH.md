# SACRED CANOPY V6.3 — Announcement and Mascot Fix

## Changes
- The mascot launcher and its in-chat image now use the original image orientation (the previous horizontal flip was removed).
- Admin activity announcements are normalized across legacy and current field names.
- Date values from Firestore Timestamp, ISO strings, epoch values, and `datetime-local` inputs are normalized safely. This avoids the legacy `[object Object]` date issue that could cause an enabled announcement to be hidden.
- Saving an activity stores start/end dates as ISO timestamps and keeps blank dates unbounded.
- Saving/loading the maintenance notice now converts Firestore timestamps correctly for the form.
- Homepage carousel keeps the curated website knowledge slides and inserts active admin announcements as slides before them.
- Homepage, Help, and notification bell continue listening in real time to `siteActivities` and `siteSettings/maintenanceNotice`.
- Opening an empty maintenance form defaults the “show announcement” checkbox to enabled; existing disabled notices remain disabled unless the admin enables them.

## Firestore Rules
No new Firestore rules were added in this version. The existing `firestore.rules` already allows public reads of `siteActivities` and `siteSettings/maintenanceNotice`, while writes are restricted to admins with Firebase Auth Custom Claims (`request.auth.token.admin == true`).

If the live Firebase project has older rules deployed, review `firestore.rules` and deploy it together with hosting:
```powershell
firebase use sacred-canopy-168ef
firebase deploy --only firestore:rules,hosting:sacred-canopy-99
```

Do not replace the rules with unrestricted public writes.

## Local testing
```powershell
npm install
npm run build
npm run dev
```

If an announcement still does not appear, confirm in Firebase Console > Firestore Data:
- activity/banner: `siteActivities/{activityId}` with `enabled: true`, non-empty `title` and `message`
- maintenance notice: `siteSettings/maintenanceNotice` with `enabled: true`, non-empty `title` and `message`
- optional start/end times include the current time in the intended local timezone.
